# Ecoberg Backend

FastAPI backend for the Ecoberg React app.

## Run

```bash
npm run setup:api
npm run dev:api
```

API docs are available at `http://localhost:8000/api/docs`.

## Main Endpoints

- `GET /api/health`
- `GET /api/dashboard`
- `GET /api/explorer`
- `GET /api/compare`
- `GET /api/per-capita`
- `GET /api/sources`
- `GET /api/admin`
- `POST /api/contact`
